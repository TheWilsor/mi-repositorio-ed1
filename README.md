# Ecosistema Autónomo Local - Claude Code & Ollama

Este repositorio contiene un agente de desarrollo local, privado y autónomo impulsado por Ollama (`dagbs/qwen2.5-coder-7b-instruct-abliterated`).

## Arquitectura del Sistema
- **`core/`**: Contiene los puentes lógicos para interactuar con el sistema de ficheros, Git y Obsidian.
- **Portabilidad**: Todas las rutas son relativas a la raíz del repositorio (`ROOT_DIR`).
